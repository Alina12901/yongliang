# 用量记账（极简版）— SillyTavern 扩展

只做一件事：按模型记下「用了几次 / 输入多少 token / 输出多少 token」，单价你自己填，面板上算个大概的钱。

- 按量计费：填「输入 / 输出」的每百万 token 单价
- 按次计费：填「每次」多少元，只看次数
- 数据存在酒馆的 `settings.json` 里，跟着酒馆备份走，不会丢

## 安装

酒馆 → 扩展程序（Extensions）→ 安装扩展（Install extension），粘贴这个地址：

```
https://ghproxy.net/https://github.com/Alina12901/yongliang.git
```

点「安装」，装完刷新页面（F5）。顶部「扩展程序」面板里会出现「用量记账（极简）」，魔法棒菜单里也有入口。

> `ghproxy.net` 只是 GitHub 的加速地址，国内直连 github.com 打不开时用它；能直连的话换成 `https://github.com/Alina12901/yongliang.git` 也一样。

## 更新

扩展本身是个 git 仓库，更新就是 `git pull`：

- **手动**：点开「扩展程序」面板里的这一条，酒馆会检查一次版本；有新版本时名字会标黄并出现 **Update** 按钮，点一下就是拉取，提示 “Reload the page to apply updates”，刷新页面生效。
- **提醒**：本扩展的 `manifest.json` 里已经打开 `auto_update`，所以只要你在「扩展程序」设置里勾上 **Notify about extension updates**，有更新时每天会弹一次提示（一天最多一次）。
- 版本号写在 `manifest.json` 的 `version` 字段里，更新记录见仓库的 commit 历史。

## 用法

1. 正常聊天，每收到一条模型回复，对应模型那行的 `次数` +1，同时累计输入 / 输出 token
2. 行首那个小标签是**这套模型挂在哪个接口下**（连接配置的名字，或者 openai / claude / deepseek / 自定义 · 域名 这种）
3. 在那一行选「按量」或「按次」，填单价
4. 右边的数字就是估算花费；底部一行是合计

## 多个 API 一起用

每个「接口 + 模型」组合单独一行，互不干扰：

- 你在连接配置里建了「DeepSeek 官方」和「某中转站」两套，两边都有 `deepseek-chat` → **两行，各自记次数和 token，各自填单价**
- 换了模型就自动多一行，切回去继续累加到原来那一行
- 切接口时那一行的小标签会跟着变，一眼能看出这笔钱花在哪个站


## 今日 / 本周 / 全部

设置面板顶部有三个切换：**今日**、**本周**、**全部**（= 从装好到现在一共花了多少）。

- 每次回复除了累加到模型的累计数字，还会记一笔当天流水（按「日期 + 接口 + 模型」存）
- 「本周」按周一起算，从本周一到今天
- 切区间时，单价输入框还是同一批（价格只按「接口 + 模型」存一份，不按天变），只是次数和 token 换成该区间的
- 逐日流水默认保留最近 400 天，更早的自动清掉，累计数字不受影响

魔法棒里的「用量记账」点开是三行总览：今日 / 本周 / 全部，下面再列每个模型的累计。

## 手机上用

酒馆的移动端断点是 1000px，这个扩展跟着同一个断点自适应，不用另装手机版：

- 三个档位按钮铺满整行，手指点不容易点错
- 每个模型拆成三行：接口+模型 / 次数与 token / 单价与金额，不会横向挤爆
- 单价输入框收窄到 62px，金额和清零按钮仍在同一行右侧
- 魔法棒汇总弹窗在窄屏上把「次数/token」换行显示，不会溢出

手机要能打开酒馆，得先让酒馆监听局域网（在你自己的 `config.yaml` 里）：

```yaml
listen: true
whitelistMode: true
whitelist:
  - 127.0.0.1
  - ::1
  - 10.0.0.23          # 换成你手机上看到的那个局域网 IP（每家路由都不一样）
```

然后手机浏览器访问 `http://<电脑局域网 IP>:8000`。手机上打开面板的路径是：左上角菜单 → 扩展程序 → 用量记账。

## 几点说明

- **是估算，不是账单**。token 数是拿酒馆自带的分词器数的，跟厂商的实际计数会有 1~3% 的差别。
- 上游的**缓存命中折扣**这里算不出来，所以开了提示词缓存的话，实际会比显示的便宜。
- **换 swipe / 重新生成**每次都算一次，跟你被扣费的次数一致。
- 角色卡开场的问候语、你自己发的消息不计费，不会算进去。
- 用 KoboldAI / Oobabooga 这类文字补全接口时，输入 token 拿不到（那些接口本来也多数免费），只统计次数和输出。
